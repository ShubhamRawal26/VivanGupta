## 🌟 Platform Overview

The **Vivan Gupta JEE Counseling Platform** is an enterprise-grade, high-conversion web application designed to guide engineering aspirants through the intricate admission mechanics of Indian technical institutes. Founded and led by **Vivan Gupta (IIIT Pune Alumnus)** and powered by **NexGen Digital**, the platform replaces guesswork with historical cutoff trendlines, quota exploitation mechanics, and multi-bracket choice-filling algorithms.

## ⚡ Key Highlights & Core Capabilities

- **Zero-Dependency Vanilla Architecture**: Ultra-fast initial page loads with pure ES6+ JavaScript, semantic HTML5, and native CSS custom properties.
- **Dynamic Simulation Engine**: Client-side rank and college prediction calculating instant tier opportunities, allotment probabilities, and package estimations.
- **Luxury Gold & Obsidian Design Tokens**: Crafted with refined amber gold (`#F59E0B`), rich obsidian black (`#08090C`), and crisp light mode palettes.
- **Ambient Canvas Particles**: Zero-dependency 60 FPS floating particle canvas that responds dynamically to active theme palettes.
- **Auto Scroll-Spy & Reading Progress**: Real-time viewport offset tracking with active nav pill indicators and top progress gradient bar.
- **Accessible & Responsive**: Fully accessible (WCAG 2.1 compliant), mobile-first responsive drawer navigation, and reduced-motion fallbacks.

### 1. Real-Time Rank & College Predictor Engine
- **Percentile Threshold Mapping**: Dynamic evaluation across multiple percentile tiers (`99.50+`, `98.00-99.49`, `95.00-97.99`, `90.00-94.99`, `<90.00`).
- **Category Quota Logic**: Real-time evaluation of OPEN, GEN-EWS, OBC-NCL, SC, and ST seat pools.
- **Branch Preference Filters**: Instant switching between Computer Science/AI, Electronics/VLSI, Core Electrical/Mechanical, and Any Top Tier College.
- **Dynamic Metric Projections**: Computes recommended admission path (e.g. *JoSAA Float ➔ CSAB Special Upgrade*), tier jump elevation factor, package brackets, and allotment probability confidence scores.

### 2. Multi-Tier Choice Matrix Algorithm
- **Tier-1 Ambition Bracket**: Strategic high-cutoff choices placed strategically without risking seat rejection.
- **Tier-2 Core Target Bracket**: Realistic allocation zone maximizing institute NIRF rank vs preferred branch.
- **Tier-3 Bulletproof Safety Bracket**: Fail-safe choices calibrated against 5-year closing rank volatility.
- **Home State (HS) & Other State (OS) Quota Calibration**: Unlocks NIT 50% reservation quotas and female supernumerary seat pools.

### 3. Tri-Mode Theme System (Obsidian Dark / Crisp Light / System Auto)
- **Segmented Control Switcher**: Custom CSS segmented toggle with active sliding state and ARIA pressed attributes.
- **Dynamic Asset Switching**: Brand logos and NexGen Digital badges dynamically switch between dark and light variants.
- **OS Theme Sync**: Automatic listener for `prefers-color-scheme: dark` when in System/Auto mode.
- **Persistent State**: Theme preference saved locally in `localStorage.getItem('theme-mode')`.

### 4. Ambient Canvas Particle & Scroll Parallax VFX
- **Hardware-Accelerated Parallax**: Smooth vertical transformation applied to the vector grid backdrop using `requestAnimationFrame`.
- **Canvas Particle Emitters**: 28 autonomous floating nodes with collision boundary checks and theme-reactive tinting (`#F59E0B` in dark mode, `#B45309` in light mode).
- **Reduced Motion Support**: Automatically disables parallax translation and heavy animations when `prefers-reduced-motion: reduce` is detected.

### 5. Interactive Lead Capture & Priority Booking
- **Smart Form Validation**: Validates 10-digit Indian WhatsApp numbers, CRL ranks, and percentile inputs.
- **State Feedback**: Seamless asynchronous button loading animation with success state transitions and automatic timeout resets.
- **Confidentiality & Privacy Safeguards**: Transparent trust badges ensuring candidate contact details remain strictly confidential.

### 6. High-Fidelity 4K Campus Showcase & Placements
- **Iconic IIT Showcase**: Architectural front-elevation cards for **IIT Roorkee**, **IIT Bombay**, **IIT Delhi**, and **IIT Kharagpur** complete with NIRF ranks, average package stats, and opening/closing AIR ranges.
- **Verified Placement Testimonials**: Verified student success records featuring real students placed at IIT Roorkee (CSE), NIT Surathkal (ECE), IIIT Allahabad (IT), and IIT BHU Varanasi.

## 🚀 Quick Start & Running Locally

### Prerequisites

Ensure you have one of the following installed on your system:
- **Node.js** (v14.x or higher) and **npm** [Download Node.js](https://nodejs.org/)
- **Python 3.x** [Download Python](https://www.python.org/)
- **VS Code** with Live Server Extension [Download VS Code](https://code.visualstudio.com/)

---

### Step 1: Clone the Repository

```bash
# Clone the repository via Git
git clone https://github.com/ShubhamRawal26/VivanGupta.git

# Navigate into the project root directory
cd VivanGupta
```

---

### Step 2: Choose Your Local Running Method

#### Method 1: Node.js / NPX HTTP Server (Recommended)

Using the configured `package.json` dev script:

```bash
# Start the local development server on port 3000
npm run dev
```

*Or run directly using NPX without npm install:*

```bash
npx serve -l 3000 .
```

*Open your browser and navigate to:* **`http://localhost:3000`**

---

#### Method 2: VS Code Live Server Extension

1. Open the project folder in VS Code:
   ```bash
   code .
   ```
2. Install the **Live Server** extension by *Ritwick Dey* (`ms-vscode.live-server`).
3. Right-click on `index.html` in the file explorer and select **"Open with Live Server"**.
4. The site will automatically launch at **`http://127.0.0.1:5500`** with live hot-reloading on file save.

---

#### Method 3: Python 3 Built-in Server

If you have Python 3 installed, you can spin up an instant local web server with zero dependencies:

```bash
# Start Python HTTP server on port 8000
python -m http.server 8000
```

*Open your browser and navigate to:* **`http://localhost:8000`**

---

#### Method 4: Docker Containerization

You can also run the application inside a lightweight NGINX Alpine container:

```bash
# Run using official Nginx Alpine image mapping port 8080 to container port 80
docker run --name vivan-gupta-counseling -d -p 8080:80 -v "$(pwd)":/usr/share/nginx/html:ro nginx:alpine
```

*Open your browser and navigate to:* **`http://localhost:8080`**

## ⚙️ Backend, Webhook & Lead Automation Setup

The lead booking form (`#counseling-lead-form`) is designed for instant plug-and-play integration with CRM backends, WhatsApp Business APIs, Zapier, Make.com, or Google Apps Script webhooks.

### Sample Webhook Integration (`script.js`)

To forward form submissions to an external endpoint or CRM, update `initFormHandler()` in `script.js`:

```javascript
/* Example: Forwarding lead capture data to a REST API / Webhook */
async function submitLeadToWebhook(formData) {
  const WEBHOOK_URL = 'https://api.yourdomain.com/v1/leads/jee-counseling';
  
  try {
    const response = await fetch(WEBHOOK_URL, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': 'Bearer YOUR_SECRET_API_KEY'
      },
      body: JSON.stringify({
        fullName: formData.name,
        whatsappNumber: formData.whatsapp,
        jeeRank: formData.rank,
        category: formData.category,
        targetCollege: formData.notes,
        timestamp: new Date().toISOString(),
        source: 'Landing Page Lead Engine'
      })
    });

    if (!response.ok) throw new Error(`HTTP error! Status: ${response.status}`);
    return await response.json();
  } catch (error) {
    console.error('Webhook submission error:', error);
    throw error;
  }
}
```

### Environment Variables Template (`.env.example`)

If deploying to Node.js / Express / Next.js / Serverless wrappers:

## 🤝 Contributing Guidelines

Contributions, feature requests, and optimizations are warmly welcomed! Please adhere to the structured 5-step contribution flow below:

```
  ┌─────────────┐     ┌──────────────────────┐     ┌───────────────────┐
  │ 1. Fork &   │ ──► │ 2. Create Feature    │ ──► │ 3. Implement &    │
  │    Clone    │     │    Branch            │     │    Test Changes   │
  └─────────────┘     └──────────────────────┘     └─────────┬─────────┘
                                                             │
  ┌─────────────┐     ┌──────────────────────┐               │
  │ 5. Open     │ ◄── │ 4. Push Branch to    │ ◄─────────────┘
  │    PR       │     │    Your Fork         │
  └─────────────┘     └──────────────────────┘
```

1. **Fork the Repository**: Click the **Fork** button at the top right of the GitHub page.
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/rank-predictor-enhancement
   ```
3. **Commit Your Changes**: Follow the **Conventional Commits** specification.
   ```bash
   git commit -m "feat(predictor): add JAC Delhi and MHT-CET score brackets"
   ```
4. **Push to Your Branch**:
   ```bash
   git push origin feature/rank-predictor-enhancement
   ```
5. **Open a Pull Request**: Submit your PR with a detailed description of the modifications, screenshots of visual changes, and browser compatibility notes.
